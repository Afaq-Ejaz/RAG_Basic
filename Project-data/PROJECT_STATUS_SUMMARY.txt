PROJECT STATUS SUMMARY - LEARN

This project is a beginner-friendly PDF RAG app. It is not finished yet, but the main building blocks are already in place.

WHAT EXISTS
- A Python package structure under src/learn
- A FastAPI app and Inngest trigger setup in main.py
- PDF loading and chunking logic in data_loader.py
- Qdrant-based vector database wrapper in vector_db.py
- A local Qdrant storage folder in qdrant_storage/
- Dependencies configured in pyproject.toml

HOW IT WORKS
1. The app starts from main.py.
2. A PDF is processed through data_loader.py.
3. The text is split into chunks.
4. Embeddings are generated using Google GenAI.
5. Those vectors are stored in Qdrant using vector_db.py.
6. The system can later search similar content by vector similarity.

CURRENT STATUS

- End-to-end flow is not fully connected yet

SIMPLE FILE VIEW

- data_loader.py = read PDF + create embeddings
- vector_db.py = save/search vectors in Qdrant
- qdrant_storage/ = database state folder
- pyproject.toml = project setup and dependencies

This is a solid foundation for learning how a document-based AI system is built one step at a time.
