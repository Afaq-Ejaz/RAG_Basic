PROJECT STATUS SUMMARY: LEARN (PDF RAG)
========================================

OVERVIEW
A modular, event-driven PDF RAG service built with FastAPI, Inngest, Google GenAI embeddings, and Qdrant.

TECH STACK
- Language/Env : Python (>=3.14), uv
- API & Steps  : FastAPI, Inngest (durable multi-step execution)
- Ingestion    : LlamaIndex (PDFReader, SentenceSplitter)
- Embeddings   : Google GenAI (gemini-embedding-001, 3072 dimensions)
- Vector Store : Qdrant (cosine similarity, port 6333 / local storage)
- Schemas      : Pydantic v2

FILE MAP
- Project-data/CONCEPTS_DECODED.md: Deep-dive concept breakdowns & mental models
- src/learn/main.py         : FastAPI app + Inngest step workflow (`rag/ingest_pdf`)
- src/learn/custom_types.py : Pydantic schemas (`RAGChunkAndSrc`, `RAGUpsertResult`, etc.)
- src/learn/data_loader.py  : PDF loading, chunking (1000/200), and Gemini embeddings
- src/learn/vector_db.py    : Qdrant client wrapper (init collection, upsert, search)
- src/learn/qdrant_storage/ : Local disk storage for Qdrant
